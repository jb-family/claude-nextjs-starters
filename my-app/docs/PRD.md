# StarterKit MVP PRD

## 프로젝트 개요

**목적**: 1인 개발자 및 소규모 팀이 Next.js 기반 웹 애플리케이션을 처음부터 구축하지 않고 즉시 개발에 착수할 수 있도록 검증된 스타터킷 템플릿을 제공한다.

**타겟 사용자**: 모던 웹 스택(Next.js, TypeScript, Tailwind CSS)으로 빠르게 프로토타입 또는 SaaS 제품을 만들려는 1인 개발자 및 소규모 개발팀.

**핵심 가치**: 반복 설정 작업 제거. 라우팅, 인증 UI, 레이아웃, 공통 컴포넌트, 폼 처리, 상태 관리 기반이 사전 구성되어 있어 첫 커밋부터 비즈니스 로직에 집중할 수 있다.

## 사용자 여정

```
1. 랜딩 페이지 (/)
   ↓ "시작하기" 또는 "문서 보기" 클릭

2. [분기]
   [문서] → 문서 페이지 (/docs) → 스타터킷 구조 확인 후 대시보드로 이동
   [시작]  → 로그인 페이지 (/login)

3. 로그인 페이지 (/login)
   ↓ 이메일/비밀번호 입력 후 제출
   [성공] → 대시보드 (/dashboard)
   [미가입] → "회원가입" 링크 클릭 → 회원가입 페이지 (/signup)

4. 회원가입 페이지 (/signup)
   ↓ 이름/이메일/비밀번호/비밀번호확인 입력 후 제출
   [성공] → 로그인 페이지로 이동 (toast 표시)
   [실패] → 인라인 유효성 오류 표시

5. 대시보드 (/dashboard)
   ↓ 통계 카드 및 최근 활동 확인
   [예제 탐색] → 예제 목록 페이지 (/examples)
   [문서 확인] → 문서 페이지 (/docs)

6. 예제 목록 페이지 (/examples)
   ↓ 예제 카드 클릭
   → 각 컴포넌트 예제 페이지 (버튼/폼/테이블/다이얼로그/토스트/카드)
```

## 데이터 모델

현재 버전은 백엔드 연동 없이 UI 템플릿으로만 동작하므로 실제 데이터베이스 스키마는 없다. 아래는 코드에 정의된 TypeScript 타입 기반의 논리적 모델이다.

### User (사용자)

| 필드 | 설명 | 타입/관계 |
|------|------|----------|
| id | 고유 식별자 | string |
| name | 사용자 이름 | string |
| email | 이메일 주소 | string |
| avatarUrl | 프로필 이미지 URL | string (선택) |
| role | 권한 역할 | "admin" / "user" / "guest" |
| createdAt | 계정 생성일시 | string (ISO 8601) |
| updatedAt | 계정 수정일시 | string (ISO 8601) |

### Activity (활동 로그)

| 필드 | 설명 | 타입/관계 |
|------|------|----------|
| id | 고유 식별자 | string |
| user | 사용자 이름 | string |
| action | 수행한 작업 설명 | string |
| timestamp | 작업 발생 일시 | string (ISO 8601) |
| status | 처리 상태 | "success" / "pending" / "failed" |

### DashboardCard (대시보드 통계)

| 필드 | 설명 | 타입/관계 |
|------|------|----------|
| id | 고유 식별자 | string |
| title | 지표 이름 | string |
| value | 현재 수치 | string / number |
| change | 변화율 | number |
| changeType | 변화 방향 | "increase" / "decrease" / "neutral" |

## 비기능 요구사항

### 접근성

- Radix UI 기반 컴포넌트를 사용하여 키보드 탐색 및 스크린 리더 접근성 기본 보장
- 모든 인터랙티브 요소에 적절한 aria-label 제공

### 반응형 디자인

- 모바일(320px) ~ 데스크탑(1920px) 전 범위 대응
- 사이드바: 768px 미만에서 Sheet 드로어로 자동 전환
- 그리드 레이아웃: 화면 크기에 따라 1/2/3/4 컬럼 자동 조정

### 성능

- Next.js App Router의 서버 컴포넌트 기본 활용으로 초기 번들 크기 최소화
- TanStack Query의 staleTime(60초) 설정으로 불필요한 재요청 방지
- 이미지 최적화: Next.js Image 컴포넌트 사용 권장

### 코드 품질

- TypeScript strict 모드 적용
- ESLint + eslint-config-next 규칙 준수
- 컴포넌트/훅/유틸리티의 명확한 디렉토리 분리
